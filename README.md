# AgentMe / Sage

AgentMe is the GitHub home for Sage, a local AI operating system designed to run on Windows 11.

## Current Phase

Phase 1 — Foundation

## Core Goals

- Sage Commander
- Inbox and approval system
- Long-term memory
- Voice control
- Specialist agents
- Jarvis-style HUD
- Automation and integrations

## Planned Stack

- Python + FastAPI
- React + Vite + TypeScript
- PostgreSQL
- Qdrant
- Ollama
- LM Studio
- Faster-Whisper
- Piper
- Docker Desktop
- n8n
- Playwright
- GitHub Actions

## Safety Rules

- LOW risk tasks may run automatically
- MEDIUM risk tasks require KurtisC approval
- HIGH risk tasks are blocked
- No automatic trade execution
- No automatic money movement
- No credential sharing
- No critical file deletion
